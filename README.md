### 🗣️ How to Use the **Muyan-TTS Speech Generator**  
*(Beginner-Friendly — No Terminal Experience Needed)*

This guide walks you through downloading, setting up, and running the app—even if you're not comfortable with terminal commands.

---

#### ✅ Step 1: Download the Original Project
- Go to the GitHub repository:  
  🔗 [https://github.com/MYZY-AI/Muyan-TTS](https://github.com/MYZY-AI/Muyan-TTS)
- Click the green **"Code"** button, then choose **Download ZIP**.
- After downloading, extract the ZIP file to a folder on your computer.

---

#### ✅ Step 2: Install Python & Streamlit

1. If Python isn't installed, download it from:  
   🔗 [https://www.python.org](https://www.python.org)

2. Open your terminal (Command Prompt on Windows, Terminal/iTerm on macOS/Linux), and install Streamlit:
   ```bash
   pip install streamlit
   ```

---

#### ✅ Step 3: Add `gui.py` to the Project

- Copy your custom `gui.py` file into the extracted `Muyan-TTS` project folder.
- Make sure `gui.py` is in the main directory of the project (same level as other scripts like `app.py` if present).

---

#### ✅ Step 4: Run the Application

In your terminal:

1. Navigate to the project folder (replace the path below with your actual path):
   ```bash
   cd path/to/Muyan-TTS
   ```

2. Run the app using Streamlit:
   ```bash
   streamlit run gui.py
   ```

---

#### ✅ Step 5: Use the Interface

- After running the command, a browser window will open.
- You'll see the **Muyan-TTS Speech Generator** interface (as shown in your image).
- Upload a reference voice (WAV), input your text, and click **Generate Speech**.
